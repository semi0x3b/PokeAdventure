부모님이 관리하는 기기 수첩

두근두근 모험은 부모가 열어 주는 어린이 학습 게임입니다. 이름에는 실명 대신 별명을 써 주세요. 아이의 생년월일·연락처·사진을 입력받지 않습니다. 부모 수첩은 서버 회원 계정이 아니며, 같은 주소로 접속해도 다른 기기의 기록과 연결되지 않습니다.

기기에 저장하는 항목과 목적

수첩 별명, 비밀번호 확인용 무작위 소금값과 해시, 로그인 실패 횟수·잠금 시간, 잡은 친구·동행·마당·학습·출석·선물 기록과 설정을 브라우저 localStorage에 저장합니다. 수첩을 열고 진행을 이어 가며 중복 보상을 막기 위해 사용합니다. 실제 비밀번호를 그대로 저장하지 않습니다.

이 버전은 수첩 별명·비밀번호 확인값·게임 기록을 서버로 보내거나 다른 기기와 자동으로 맞추지 않습니다. 구글 로그인·광고·분석 도구·카메라·마이크·정밀 위치 권한 기능을 넣지 않았습니다.

외부 연결과 읽어 주기

화면은 Vercel에서, 포켓몬 그림·도트·울음소리는 PokeAPI와 GitHub 원본 자료원에서 받습니다. 원본 연결에 실패하면 같은 공개 파일을 jsDelivr CDN에서 받을 수 있습니다. 호환성을 위해 Pokémon Showdown 울음소리를 사용할 수 있습니다. 이 연결에서 IP 주소·브라우저 정보·요청 주소·접속 시각 등이 해당 제공자에게 전달되거나 로그에 남을 수 있습니다. 기기 저장형이라고 해서 외부 접속 정보까지 전혀 생기지 않는 것은 아닙니다.

문제 읽기와 음성 안내는 브라우저·운영체제의 음성 합성을 사용합니다. 로컬 한국어 음성을 우선하지만, 기기 설정과 지원 음성에 따라 문제·안내 문구가 음성 제공자의 서버에서 처리될 수 있습니다. 마이크로 아이 목소리를 녹음하지 않습니다. 읽어 주기를 원하지 않으면 게임 설정의 소리를 꺼 주세요.

외부 제공자의 저장 위치·보관 기간·권리 행사에는 해당 제공자의 정책이 적용됩니다. Vercel 개인정보 안내 · GitHub 개인정보 안내. 브라우저·운영체제의 음성 설정과 정책도 확인해 주세요.

보관·삭제·백업

기기 기록은 부모가 이 사이트의 데이터를 지우거나 브라우저·운영체제가 정리할 때까지 남습니다. 서비스워커는 화면과 받은 자원을 Cache Storage에 보관합니다. 로그인 폼·비밀번호·게임 기록·API 응답을 자원 캐시에 넣지 않습니다. 음원 호환용 종 이름과 안내를 본 횟수 같은 보조 설정도 기기에 남을 수 있습니다.

설정의 처음부터 다시 하기는 진행만 초기화합니다. 부모 잠금·보조 설정·자원 캐시까지 없애려면 브라우저 설정에서 이 사이트의 저장 데이터와 캐시를 삭제하세요. Safari와 홈 화면 앱은 기기에 따라 저장 공간이 다를 수 있습니다. 운영자가 기기 기록을 원격으로 열람·삭제·복구하지는 못합니다.

이전 서버 저장 버전을 이용했다면 당시 서버에 남긴 자료는 이번 기기 저장 전환이나 기기의 초기화로 자동 삭제되지 않습니다. 이전 서버 기록에 관한 문의는 아래 운영자 문의 경로에 개인정보 없이 요청 종류만 적어 주세요. 이 안내의 기기 보관 기간을 과거 서버 자료의 삭제 완료로 이해하지 마세요.

기기 분실·브라우저 정리에 대비해 설정에서 JSON 백업을 보관해 주세요. 백업에는 진행만 담고 수첩 별명·비밀번호·확인값은 담지 않습니다. 백업은 진행을 복원할 수 있는 파일이므로 다른 사람이나 공개 게시판에 보내지 마세요. 내려받은 백업 파일은 부모가 직접 삭제해야 합니다.

부모님의 제안·오류·개인정보 문의

운영자는 GitHub 계정 semi0x3b입니다. 문의는 부모님 제안·오류 제보로 받습니다. GitHub 계정이 필요하며, GitHub 사용자명·직접 쓴 본문·첨부·답변·작성 시각이 공개되고 운영자도 볼 수 있습니다. 문의 응답과 개선 검토에 사용하며, 게시물은 삭제되기 전까지 남을 수 있습니다. 게임 기록은 자동 첨부하지 않습니다.

아이 이름·얼굴·연락처·비밀번호·백업·저장소 전체를 올리지 마세요. 기기 기록에 관한 질문은 기록 없이 현상만 설명하고, 공개 게시물의 수정·삭제가 필요하면 개인정보를 다시 적지 말고 해당 게시물 주소로 요청해 주세요. 운영자가 관리할 수 있는 게시물에 대해 확인하지만 이미 복사·검색 저장된 자료까지 회수할 수는 없습니다. 취약점·정보 노출 신고는 비공개 보안 신고를 이용하세요. 이 창구들도 부모가 사용합니다.

부모 잠금과 변경 안내

숫자 비밀번호는 아이가 혼자 게임을 여는 것을 줄이는 앱 안 잠금입니다. 기기 자체 잠금·스크린 타임이나 개발자 도구를 쓸 수 있는 사람에 대한 접근 통제를 대신하지 않습니다.

서버 동기화·계정 연동·새 수집 기능을 넣기 전에는 이 안내와 필요한 보호 절차를 다시 검토합니다. 현재 안내의 변경은 적용일과 문서 변경 기록으로 확인할 수 있습니다.
