# 필드 포켓몬 그림 출처

PMDCollab/SpriteCollab 공개 자료의 Walk/Idle 원본이다. 이미지 픽셀은 수정하지 않았고, 게임에서 재생하는 프레임과 방향만 선택한다. 같은 종의 검증된 팬 Alternate를 우선하고 나머지는 기본 원본을 선택했다.

원작 CHUNSOFT의 `Unspecified`는 라이선스 미지정으로 그대로 기록하며 CC BY-NC 또는 자유 사용으로 바꾸어 표시하지 않는다. 팬 파일은 각 credits.txt가 실제로 적은 라이선스를 보존한다. 공개 저장소에 있다는 사실만으로 모든 자산의 권리를 포괄하는 라이선스가 생기는 것은 아니다.

사용조건 원문: [CC BY-NC 4.0](LICENSE.CC_BY-NC_4.md), [PMDCollab_1](LICENSE.PMDCollab_1.md), [PMDCollab_2](LICENSE.PMDCollab_2.md). CC BY-NC는 비상업·크레딧·출처·변경 표시, PMDCollab_1은 원작자 크레딧 유지, PMDCollab_2는 원작자 크레딧 유지와 비영리 조건이다. 이 표는 원작 자산의 별도 권리를 팬 라이선스로 바꾸어 설명하지 않는다.

연락처 데이터는 이 묶음에 포함하지 않는다. 기여자·사용 조건은 아래 표에, 세부 기여 기록은 각 항목에 연결한 원본 자료에 있다.
