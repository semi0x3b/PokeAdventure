# 게임 소개 화면

2026-11-18, 운영과 같은 게임 코드에서 Aside로 촬영한 실제 화면입니다. localhost 전용 시험 수첩을 사용했고, 소개할 기능이 보이도록 모은 친구·동행·마당 기록을 준비했습니다. 실제 아동 자료나 실사용자의 플레이 기록이 아닙니다.

- `title.webp`·`battle.webp`·`writing.webp`·`dex.webp`·`yard.webp`: 실제 화면. 브라우저의 비밀번호 저장 알림을 닫고 화면 전환이 끝난 뒤 촬영했습니다.
- `field-walk.gif`: 클릭/키보드로 탐험하는 실제 필드의 연속 캡처. 걷기 16장 중 일부를 사용했습니다.
- `capture.gif`: 직접 볼까지 걸어가 그림자·문제2개를 맞힌 뒤 포획 연출 24장을 캡처했습니다. 끝에는 실제 잡은 결과 화면을 잠깐 유지했습니다. GIF는 소개용으로 짧게 편집했습니다.

원본과 재현 스크립트·결과는 `.test/readme-showcase/`에 모았습니다. 화면·GIF는 게임 기능을 소개하는 문서 자료이며, 등장 캐릭터·픽토그램 등 제삼자 권리를 프로젝트 코드 라이선스로 바꾸지 않습니다. 출처와 조건은 루트 README와 개별 자료 문서를 확인하세요.
