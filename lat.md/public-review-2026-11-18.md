# 공개 레포·이용 안내·제안 창구

사용자가 레포 공개 전환, 개인정보/이용조건/보안 검토, 기능 개선 창구, PokeTokenBar를 참고한 독자적인 PR 템플릿을 요청했다. 2026-11-18 `semi0x3b/PokeAdventure`의 PUBLIC 상태와 Issues·비공개 취약점 신고 활성화를 GitHub에서 확인했다.

## 범위와 설계

- 부모용 GitHub 기능 제안·오류 제보 양식. 공개 게시판임과 계정 필요, 개인정보·아이 얼굴·백업 금지를 먼저 알린다. 어떤 게임 데이터도 URL에 넣거나 자동 제출하지 않는다.
- 게임의 부모 설정에서 안내 창을 거쳐 외부 게시판으로 이동한다. 보안 취약점은 GitHub 비공개 신고로 분리한다. 로그인이 없는 사용자도 개인정보/이용조건 문서에서 문의 경로를 찾을 수 있다.
- PR은 변경된 경험부터 설명한다. 기존 화면은 같은 크기/데이터/상태의 전후 이미지, 새 화면은 새 이미지가 필수. 이미지에는 시험용 기록만 쓰고 실제 검증과 시안을 구별한다. 본문은 한국어다.
- 별도 접수 서버/익명 폼은 수집 항목·관리 표면을 늘리므로 선택하지 않았다. GitHub 이슈에 기기 기록을 자동 첨부하는 안도 배제했다. GitHub의 연령 제한 때문에 아이가 작성하는 메뉴로 만들지 않는다.
- PokeTokenBar 업스트림 템플릿의 '시각적 근거를 반드시 첨부' 원칙만 참고했다. Swift 검사나 영어 본문 규칙을 복사하지 않고 이 게임의 폰/패드·부모 잠금·기기 저장에 맞췄다.

## 검토 결과와 제한

- 저장 엔진·PIN 해시·백업 제외 항목과 기존 안내는 일치했다. 기기 저장과 외부 접속 로그를 구분해야 한다. 호스팅·외부 자료원에서 IP/요청 로그가 남을 수 있어 '개인정보를 전혀 처리하지 않는다'라고 설명하지 않는다.
- 독립 검토에서 원격 TTS 안내 누락과 앱의 개별 도트 작가 문서 링크 부재를 확인했다. 음성 제공자 처리 가능성과 소리 끄기, 공개 크레딧 링크를 보완한다.
- 공개 이슈의 GitHub 계정·본문·첨부·작성 시각도 처리되는 정보이므로 목적·공개성·삭제 요청 경로를 안내한다. 문의 경로는 개인정보 없이 현상만 적는 부모용 창구다.
- 법 제30조는 개인정보처리자의 처리방침 공개 의무를 정한다. 이 검토는 코드/공개 파일과 안내를 맞추는 검토이며 개인정보처리자 해당 여부, 위탁/국외 이전 등 모든 법률 요건을 확정하는 법률 검토가 아니다. 서버 계정·분석·구글 연동을 넣기 전 다시 판단한다.
- 이전 서버 버전 자료는 전환 과정에서 삭제하지 않았다. 이번에도 과거 DB의 자료/보관 상태를 조회하거나 삭제하지 않는다. 기기 초기화가 과거 서버 자료를 지우지는 않는다는 설명을 정책에 남겼으며 보유 현황·파기 처리는 별도 확인 사항이다.
- 캐릭터·팬 도트의 별도 권리 문제는 해결되지 않았다. API·비상업·MIT·고지는 원작 사용 허가를 만들지 않는다. 라이선스 미지정 자료도 계속 표시한다. 공개 서비스의 권리 확보를 완료했다고 보고하지 않는다.

공식 근거: [개인정보 보호법 제30조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1006185717), [Vercel 개인정보 안내](https://vercel.com/legal/privacy-notice), [GitHub 개인정보 안내](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), [GitHub 계정 연령 조건](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#b-account-terms), [Pokémon 이용 안내](https://support.pokemon.com/hc/en-us/articles/360000634094-Can-I-use-Pok%C3%A9mon-images-or-materials).

## 실행 계획

1. 기존 검사104개·변경 전 실제 설정 화면을 확보한다.
2. 양식·PR 템플릿·기여/보안 안내를 만들고 부모 설정·개인정보/이용조건·크레딧 연결을 보완한다.
3. 전체 검사/문제 검사/빌드와 Aside 세로/가로/패드·키보드·잠금 전 문의 경로를 확인한다. 공개 제보는 시험 제출하지 않는다.
4. 독립 검토, 전후 화면 직접 확인, PR → 병합 → 미리보기/운영 배포 후 실제 파일/연결을 확인한다.
