# 마당·학습·동행 개선 1.0.4

## 현재 규칙

- 테마 마당15개, 크기는 고정·마당별10마리. 초원은 처음부터, 눈은10마리 포획에 열림. 20마리부터10마리마다 열쇠 하나로 아직 잠긴 마을을 고른다. 기존 `yard`는 초원, 나머지는 `yards[theme]`, 선택한 열림은 `yardsOpen`으로 보관한다. 저장 검사와 백업도 같은 목록·열쇠 한도를 검사한다.
- 목록은3열이고 폰 세로·태블릿에서는 셋째 줄 아래를 조금 가려 스크롤을 알린다. 마당·목록의 지도 버튼은 이전 필드로, 이전 필드가 없으면 지역 선택으로 간다.
- 동행은 기본2마리, 서로 다른 포획50마리부터3마리. 배틀 대표는 첫 번째다. 저장·백업·선택·필드·배 좌석 모두 같은 용량 규칙을 쓴다.
- 숫자 가르기는224문항(기존64+추가160). 작은 수의 두 무더기, 큰 수의 열 개 묶음과 낱개를 보여 준다. 기존 범위·난이도·최근 문제 제외 규칙을 유지한다.
- 배틀 스피커는 현재 문제를 다시 읽으며 `silentOptions`를 따른다. 화면의 ‘발로 차’는 유지하고 음성 입력은 ‘발로 찬다’로 보낸다. 기기 음성 제공자에 따른 발음 차이까지 보장하지 않는다.
- 마지막 정답에는 포획 준비 문구를 쓴다. ‘가랏! 몬스터볼!’을 실제로 다 읽은 뒤 던진다. 음성이 없거나 실패하면 최대12초 안에 계속한다. 설정 창이 읽기를 취소하면 닫을 때 같은 문구부터 다시 읽으며 뒤에서 던지지 않는다.
- 글자 쓰기는 소개·낱말 전환 뒤 자동으로 읽는다. 선물·설정·소개·숨김 동안 기다리고 화면 이탈 시 예약을 취소한다. 수동 다시 듣기는 유지한다.
- 로그인 이름 기억 기본 켜짐, 기존 수첩 별명을 재사용한다. 별도 평문 PIN·로그인 토큰은 저장하지 않는다. 이름 Enter는 PIN 초점으로 이동한다. 새 진입·새로고침·30분 미사용 시 잠그며 짧은 배경 전환에는 유지한다.

## 자원과 시각 효과

- API 그림·울음소리의 허용 자료원만 받은 뒤 최대360개 캐시한다. 원본과 같은 파일의 CDN 복구 주소는 같은 키를 쓴다. 버전별 로컬 동적 자원은 별도 캐시 최대100개이며 게임기록·인증·API는 캐시하지 않는다. 전체493마리 선다운로드는 하지 않는다.
- 사막의 안내와 실제 배치가 다르던 장식은 Kenney CC0의 진짜 선인장 타일로 교체하고 시작점 근처에도 둔다. 기존 충돌 위치를 유지한다. 출처·라이선스는 README와 타일 옆 파일에 남긴다.
- 노란 모래 입자는 사막에서 끄고, 숲 낙엽의 노란색을 제거했다. 날씨 레이어는 배우보다 아래에 둔다. 사용자 기기에서 보였던 반짝임의 원인이 해당 효과 하나였다는 단정은 하지 않는다. 만남 직전의 의도된 ‘!’는 유지한다.

## 버린 안과 이유

- 모든 원작 자원을 로컬 배포물에 넣기: 기존 공개 저장소 정책에 맞지 않아, 외부 자료원과 받은 자원 캐시를 유지한다.
- 음성 길이를 고정 시간으로 추정해 바로 포획: 말이 잘리는 원인이므로 실제 종료 신호를 기다린다.
- 짧은 앱 전환마다 다시 로그인: 사용자가 긴 이용 시간을 요청해30분 미사용 기준으로 바꾸되 새 진입의 부모 잠금은 유지한다.
- 오래된 작업 전체를 원본 체크아웃에 덮어쓰기: 기존 미커밋 작업을 보존하기 위해 최신 main에서 분리한 작업 폴더에 필요한 마당 변경만 통합했다.
- 폰트 전체 재생성: 기존 ㅊ·b/p 수정과 실제 글꼴 윤곽을 보존하기 위해 확인된 글자의 경로만 고친다.

## 검증 경계

자동 검사와 Aside의 실제 localhost 시험 수첩을 사용한다. 배포 주소에서는 로그인하거나 기록을 변경하지 않는다. 실제 iPad mini/Safari의 손가락 입력·홈 화면 동작은 실기기 확인이 필요하다. 시험과 화면은 `.test/release-104/`에 보관한다.

## 획순 감사

지원하는 한글438자(독립자모51·음절387)와 영문52자를 검사했다. 한글116자218획, 영문 B/M/W/a/d/g/q7자의 누락·겹침·잘린 시작점·원형 시작 방향·꼭짓점 경계를 수정했다. 윤곽490개와 기존 ㅊ18글자의 ㅊ세획, b/p를 보존했다. 글자 쓰기와 배틀이 같은 자료를 읽는다.

윤곽 내부 여부와 완주만 검사하면 같은 획을 두 번 긋거나 가지를 빼먹어도 통과했다. 새 검사는 방향·닫힘·연결·성분별 소속·실제 골격의 빠진 구간을 함께 검사한다. 붙은 초성과 모음의 단면 전체를 쓰는 초기 안은 ‘번’의 가로를 초성까지 늘려 버려 폐기했다. 시작점 경계를 보강한116자 최종본을 사용하며128자 중간본은 배포하지 않는다.

영문은 뉴질랜드 교육부 Teaching Handwriting(12·13·16쪽, https://www.pointview.school.nz/site_files/52127/upload_files/Teaching-Handwriting-2026.pdf?dl=1)과 Benchmark 인쇄체 교재(https://resources.finalsite.net/images/v1716500511/pleasantonusdnet/gpknusmh5sq6cfvkzbzo/BenchmarkHandwriting1.pdf)를 확인했다. 교재마다 다른 펜 들기 구분은 기존 기초 인쇄체 방식을 유지한다. 한글 기준은 strokes.js에 적힌 공식 한국어 교재와 실제 Nanum Gothic 윤곽이다.

`.test/release-104/stroke-audit.json`에 변경 글자/획 번호, `tracing-result.txt`에 실제 캔버스 결과를 보관한다. `tools/repair-tracing-hangul.mjs`, `repair-tracing-rat.mjs`, `repair-tracing-chieuch.mjs`는 재실행 시 변경0이다.
