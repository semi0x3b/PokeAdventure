# 외부 그림·울음소리 복구

운영 3D 그림·실루엣·울음·필드 동행 유실 제보를 받아 같은 공개 자료를 다시 받는 경로를 보강했다.

## 확인한 사실

- PokeAPI cries latest/25.ogg는 응답 MIME audio/ogg지만 바이트 fffb94c4로 시작하는 MP3다. Showdown pikachu.mp3와 같은 길이7080바이트다. 파일 확장자와 브라우저 OGG 지원 여부만으로 고르면 안 된다.
- raw GitHub의 앞/뒤 WebP·HOME PNG·도트 원본은 점검 환경에서200이었다. Chromium 운영 점검에서도 1/4/7/25 그림을 디코딩했다. 사용자 기기의 최초 이미지 실패 원인은 확정하지 못했다. 재현했다고 주장하지 않는다.
- HOME/back/25.png는404다. 뒷모습의 호환 대체 자원은 실제 존재하는 other/showdown/back/25.gif다.
- Showdown MP3는 CORS 허용 헤더가 없으므로 서비스워커에서 mode:cors로 바꾸면 안 된다. 독립 리뷰에서 발견해 원래 Request를 유지하고 회귀 검사를 추가했다.

## 적용과 버린 안

- 같은 저장소/리비전/파일의 jsDelivr 주소를 재시도한다. 새 CDN 허용을 CSP와 개인정보 안내에 함께 반영한다. 공개 파일만이며 자격 증명을 보내지 않는다.
- 3D WebP 오류는 호환 PNG/GIF로 복구하고 정해진 목록만 순서대로 시도한다. 동행 CSS도 성공한 시트 주소를 사용한다.
- 울음은 바이트 형식을 확인해 메모리 Blob을 사용하고 재생 실패 시 MP3로 한 번 재시도한다. 늦은 응답은 소리 끄기/새 울음을 덮지 않는다.
- 미디어 캐시 v2로만 교체한다. localStorage 삭제는 기록 손실 위험으로 제외했다.
- UA만으로 Safari를 추측해 3D 전체를 바꾸는 안은 제외했다. 정상 브라우저의 그림을 유지하고 실패한 그림만 호환 경로로 보낸다.
- 그림/음원을 다시 배포물에 묶거나 서버 프록시를 추가하는 안은 기존 외부 자료 방식과 무료/기기 저장 원칙을 유지하려고 제외했다.

## 검증 범위

Node 회귀 시험은 외부 실패/CDN 복구·MP3 MIME·Showdown 요청 모드·음원 디코딩 실패 재시도·늦은 응답 차단을 검사한다. Aside는 dist를 서비스워커와 CSP가 있는 로컬 서버로 띄워 실제 동행/실루엣/호환 그림/울음 디코딩을 확인한다. 운영 점검은 기록이나 로그인 계정을 만들지 않는다. 실제 iPad Safari의 재생/홈화면 실행은 별도 기기 확인 사항이다.
