# 소문자 e의 시작 경로

기존 실제 Andika 경로는 (11.25,52.08)에서 아래로 내려가 (12.52,56.65)를 지난 뒤 중간 가로획으로 올라갔다. 시작 화살표가 아래를 가리켰으며, 오른쪽으로 먼저 긋는 기본 인쇄체 e와 달랐다. 같은 게임의 기본 인쇄체 정의는 이미 가로획부터 시작했다.

실제 윤곽 안의 가로 중심 y=50에서 왼쪽 (11.67,50)부터 오른쪽 (41.74,50)까지 첫22점만 곧게 배치했다. 뒤의 원형62점과 모든 윤곽, 다른489자의 자료는 그대로 유지한다. 글자 쓰기·시범 재생·배틀 모두 같은 자료를 쓴다.

전체 폰트 재생성이나 안내 화살표만 덮어 그리는 방법은 버렸다. 전자는 기존 수정을 잃을 수 있고 후자는 실제 입력·재생 경로와 안내가 달라진다. 기존 검사의 초반 오른쪽 이동 조건은 중간에 오른쪽으로 돌아와도 통과했으므로, 첫 구간의 일정한 높이와 오른쪽 진행·이어지는 회전 순서를 별도로 검사한다.
